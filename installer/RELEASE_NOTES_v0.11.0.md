## ✨ 新功能

### 1. 分镜头 AI 画面替换
把一条分镜拆成若干「镜头」，对任意镜头用 AI 重绘画面（换背景 / 换主体 / 换颜色材质），再合成回去替换原画面。合成后原分镜即显示替换后的视频，可随时一键切回原画面，卡片上有「替换画面」标识。适合在不重拍的情况下批量产出差异化素材。

### 2. 配音变体池·参与排列组合
每条分镜的「原声 + 各改写配音版本」可分别勾选是否「参与组合」，导出时按参与的版本自动排列组合，成倍产出配音差异化视频。检视器实时显示每条分镜「参与几档」。

### 3. 导出一律串行
批量导出改为一条一条顺序出片，避免占满机器导致全部卡顿甚至超时；进度显示「串行导出中 N/M」+ 预计剩余时间。

## 🔧 体验打磨与稳定性（本版还做了大量优化）

- **全程进度可见**：导出显示单文件百分比 + 预计剩余；分镜头合成显示「切片 / 拼接 / 混音」阶段；配音显示「N/M」；AI 生成显示「约 2~4 分钟」预期。
- **报错说人话**：合成 / 生成 / 接口异常不再把英文报错码甩给你看，统一翻译成「发生了什么 + 下一步怎么办」+ 重试入口。
- **更顺手**：主窗口记住尺寸；分镜头工作区可拖边界（实时帧数）、方向键切镜头、切分失败可重试；空白页面给「去生成方案 / 立即生成方案」直达按钮。
- **更稳**：修复导出可能的重入崩溃、配音并发下的极端崩溃与临时文件残留等问题。
