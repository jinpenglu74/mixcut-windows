## 🔧 修复：分析完成后分镜素材库空白

**如果你遇到过「导入几个视频，等分析跑完，切到分镜素材库却是空的，要关掉软件重开才看得到分镜」——就是这个。**

原因是切换页面时的一处缓存判断，让分镜库跳过了重新读取数据，界面上的分镜列表始终停在打开那一刻的状态。重启之所以有效，是因为重启后这个判断不再生效。

同时补上了两处本该有的提示：

- **分析完成会主动告诉你结果** —— 「3 个视频分析完成，共 48 个分镜」，并带「去分镜素材库」按钮直接跳过去。
- **分镜库空的时候会说清楚是哪种空** —— 正在分析中会显示转圈和「AI 正在切分镜头，完成后会自动出现」；一个分镜都没有会给「去导入素材」；只是被搜索/筛选挡住了，会告诉你项目里其实有多少个分镜并给「重置筛选」。

以前无论哪种情况都只显示「没有符合条件的分镜」，分析还没跑完的时候看到这句，很容易以为软件坏了。

## 🛡️ 修复：三个会让你丢数据或白花钱的问题

**语音模型下载损坏后再也修不好** —— 网络中途断开时，下了一半的模型文件会被当成完整模型保存下来。之后设置页显示「已就绪」、依赖检查也是绿的，但每次语音识别都失败，而且点「重新下载」还是没用（因为它认为模型已经在了）。唯一的出路是手动去文件夹删掉。现在下载完会核对文件大小，不完整就自动重试；换下载源时也会丢弃上一个源的残留文件。

**已经付过费的 AI 画面生成任务，崩溃后拿不回来** —— 提交给 AI 的画面替换任务是异步的，提交成功就已经计费。如果这期间软件崩了或被强制关闭，重启后这个任务会永远停在「生成中」，而界面上只有超时状态才会出现「重试」按钮。结果就是：任务号还在、云端 24 小时内还能免费取回结果，你却拿不到，钱白花。现在启动时会自动认领这些任务，能免费取回的会出现「重试」按钮。

**导出失败或取消会留下半成品视频** —— 中断产生的 mp4 通常还能双击打开，只是内容不全。批量导出 20 条中途取消，这个坏文件就混在 19 个成品里，肉眼分不出来。现在失败或取消会自动清理掉。

## 🔒 安全：API Key 不会再随诊断包外发

部分 AI 服务的错误信息里会回显请求头，其中包含你的 API Key，而这些信息会被写进日志。「导出诊断日志」打包的正是这些日志——你把它发给开发者时，密钥也就跟着出去了。

现在所有 AI 服务的错误信息在写进日志前都会先抹掉密钥，导出诊断包时还会再过滤一遍。

## 💬 报错全面人话化

以前不少地方会把英文原文直接丢给你，比如：

```
配音合成失败：API Key 无效或未授权
（接口返回：HTTP 401 {"code":"InvalidApiKey","message":"Invalid API-key provided."...}）

合并失败：视频处理失败 (exit -1073741515): ...
```

这一版把所有报错都改成了「发生了什么 + 为什么 + 下一步怎么办」，并且区分了具体原因——磁盘满、文件被占用、没有权限、网络不通、请求超时、AI 输出被截断，各给各的处理建议，不再统统显示「处理失败，请重试」。

其它相关改进：

- **分镜头替换工作区**（AI 画面替换）的错误提示会说明**这次有没有扣费**，并且错误横幅现在带「重试」按钮，不再是读完就没辙。
- **逐句字幕编辑器**：以前时间调完保存失败是完全静默的，关掉窗口改动就没了；读取失败还会伪装成「还没有字幕数据」，诱导你去点「重新自动对齐」，反而把原本正确的数据覆盖掉。现在这两种情况都会明确告诉你，并提示不要误操作。
- **批量导出**：结果面板不再一律显示「导出失败」——5 个成功 3 个时会显示「部分完成：3/5 个已导出」，并提供「只重试失败的 2 个」，不会把已经导好的重导一遍。
- **拆分分镜**：预览加载失败时会说明可能原因和下一步，并禁用确认按钮（以前还能点，会按一个没意义的位置切开）。

## 🎨 界面：一屏能看到的分镜多了 3 倍

分镜卡片按 macOS 版的尺寸重做（400×542，原先 474×660）。全屏下从**一行放不下几张、一屏看不到一整行**，变成**并排 3 列**。

- 帧边界面板砍掉了多余的标题行，末帧时间码和帧率移到悬停提示里。
- 语义标签、位置、质量分合并到同一行。
- 字幕字号滑块从「每张卡一个」移到顶部工具栏——它本来就是全片统一的一个值。
- **IN / OUT 现在显示帧号**：加减按钮一次调 1 帧，之前显示的却是秒数，点一下数字只动 0.04，根本对不上。

其它：删除操作按 Ctrl+Z 撤销成功时会明确提示「已撤销：xxx」（以前成功了反而没有任何反馈）；批量配音和删除 AI 替换画面加了计费/破坏性二次确认。

## 📝 说明

- 首次启动如遇 Windows SmartScreen 拦截，点「更多信息 → 仍要运行」即可（应用尚未做代码签名）。
- 数据（视频 / 分镜 / 方案）默认存在用户目录，可在「设置 → 通用」里迁移到别的盘。
- 遇到问题可在「设置 → 关于 → 导出诊断日志」一键打包日志（已自动脱敏，不含 API Key）发给开发者。
